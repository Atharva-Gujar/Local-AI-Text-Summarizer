# 🔑 IMPORTANT UPDATE - API Key Required

## What Changed?

Hugging Face now requires an API key for their inference API. Don't worry - **it's still completely free!**

## ✅ How to Get Your Free API Key

### Step 1: Go to Hugging Face
Visit: **https://huggingface.co/settings/tokens**

### Step 2: Sign Up (Free)
- Click "Sign Up" if you don't have an account
- Or log in if you already have one
- **No credit card required!**

### Step 3: Create a Token
1. Click the **"New token"** button
2. Give it a name (e.g., "Summarizer")
3. Select **"Read"** role
4. Click **"Generate token"**

### Step 4: Copy the Token
- Copy the token that starts with `hf_...`
- Save it somewhere safe (you'll need it each time)

### Step 5: Use in the App
- Paste your token in the **"Hugging Face API Key"** field
- The app will remember it for your session
- Generate summaries as usual!

**Yes!** Hugging Face provides free access with generous limits.

### How many requests can I make?
The free tier has rate limits, but they're quite generous for personal use.

### Can I share my API key?
It's best to keep it private, but it's not a sensitive credential. Just don't post it publicly online.

### What if I lose my key?
Just create a new one! You can have multiple tokens.
